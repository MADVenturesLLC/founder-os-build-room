B4. Install and start the service. I create ~/.config/systemd/user/buildroom-gateway.service with exactly this content:
[Unit]
Description=Build Room Gateway daemon (1880c12d)

[Service]
Type=simple
WorkingDirectory=%h/buildroom-gateway-056ffd1
Environment=BUILDROOM_CONTROL_PLANE_URL=https://rare-enjoyment-production-0869.up.railway.app
ExecStart=%h/.nvm/versions/node/v22.23.2/bin/node dist/packages/gateway-daemon/src/main.js
Restart=on-failure
RestartSec=30
KillSignal=SIGTERM
TimeoutStopSec=20

[Install]
WantedBy=default.target
Then I run: systemctl --user daemon-reload; systemctl --user enable --now buildroom-gateway.service; and sudo loginctl enable-linger "$USER", so that my user's services start at boot without a login. The unit holds no secret: the daemon reads its own key from systemd-creds when it starts, as before, and that read is part of starting it. A clean SIGTERM exits 0 and is not restarted; any other exit is restarted after 30 seconds.
